## Overview

Aqua Sentinel is an innovative water quality monitoring system designed to provide real-time alerts on water safety. The system measures key parameters such as pH, turbidity, temperature, and dissolved oxygen to assess water quality. It is intended for use in domestic water safety, agriculture, and industries, helping to detect contamination and ensure water remains within safe limits.

### Prerequisites

1. Install [Python](https://www.python.org/downloads/).
2. Install [Git](https://git-scm.com/).
3. install ardiuno IDE [Ardiuno IDE](https://www.arduino.cc/en/software)
4. Clone this repository:
   bash
   git clone https://github.com/PYEXPO25/T019_TechieZeals
   

### Installation

1. Navigate to the project directory:
   bash
   cd T019_Techie_Zeals
   
2. Create a virtual environment:
   bash
   python -m venv venv
   
3. Activate the virtual environment:
   - On Windows:
     bash
     venv\Scripts\activate
     
   
4. Install dependencies:
   bash
   pip install -r flask,Dash,Json,NUmpy,Pandas
   
5. Navigate to source
   bash
   cd source
   

---

## Start the Application

1. Run the Flask application:
   bash
   flask run
   
2. Open your browser and navigate to:
   
  http://127.0.0.1:8050/
